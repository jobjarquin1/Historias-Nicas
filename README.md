# 🌎 Historia Verdadera de Nicaragua

## 📌 Objetivo del Proyecto

Este proyecto busca preservar y difundir la historia auténtica de Nicaragua mediante un sitio web informativo, atractivo y fácil de navegar. El sitio presentará eventos, documentos y testimonios basados en fuentes confiables, fomentando la educación y el acceso a la memoria histórica.
